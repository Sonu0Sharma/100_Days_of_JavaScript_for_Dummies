> **Context:** This repository documents my hands-on exploration of JavaScript fundamentals across progressive learning sprints. The focus is on building familiarity through iterative coding exercises and mini-projects — the code here reflects a learning journey rather than production-grade systems.

## What This Covers

- **Language Fundamentals:** Data types, operators, conditionals, loops, and string manipulation methods.
- **Functions & Functional Methods:** Higher-order functions, arrow functions, and array methods (`map`, `filter`, `reduce`).
- **DOM & Browser APIs:** DOM querying, dynamic element manipulation, and event-driven UI updates.
- **Object-Oriented JavaScript:** Prototypes, classes, constructors, methods, and class inheritance.
- **Error Handling:** Robust error interception and debugging using `try...catch` blocks.
- **Asynchronous Programming:** Managing asynchronous flows using callbacks, Promises, chaining, and `async/await`.
- **Interactive Mini-Projects:** Practical browser implementations including Tic-Tac-Toe and Rock Paper Scissors.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Sonu0Sharma/100_Days_of_JavaScript_for_Dummies.git

# Navigate to a specific topic or game (e.g., Tic-Tac-Toe)
cd 100_Days_of_JavaScript_for_Dummies/Sprint3/L10_Tik_Tak_Toe_game

# Open the HTML file in your browser
open index.html
```
